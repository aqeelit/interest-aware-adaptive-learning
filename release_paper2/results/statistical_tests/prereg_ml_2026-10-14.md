## Definitions (whole round)

- Interest columns = 21 columns: the 20 activity-type click-shares plus
  resource_diversity_entropy. Columns that are constant in a setting (e.g. folder and
  repeatactivity at t28) are kept in the models, their ICC is reported as undefined, and their
  centered values are 0. No column is dropped.
- Settings:
  - FULL = full-course features, Withdrawn included, same row set as the manuscript's D-vs-E
    comparison (the actual N is reported); base = E features (B + C).
  - EARLY_t28 and EARLY_t56 = VLE-only, cutoff-first truncation, same risk set and course
    controls as the earlier EARLY rounds; base = C_early.
- Course centering and course means use only the students of that presentation in the analysed
  sample, features only, no labels. This is written in the header of every output file that
  uses them.
- Pairwise tests are key-aligned by (id_student, code_module, code_presentation). Bootstrap =
  student-level (id_student), 1000 resamples, seed 42.
- Criterion "replicates in a module": the student-level bootstrap 95% CI of delta-Accuracy
  excludes 0 in the same direction for BOTH LR and GBM (per cutoff).

## Protocol

- Seed 42. LR = train_evaluate_oulad.make_pipeline (median impute + standard scaling + LR);
  GBM = HistGradientBoostingClassifier(random_state=42), library defaults.
- Stratified 5-fold = StratifiedKFold(5, shuffle, random_state 42), as in robustness_common.
- McNemar on key-aligned predictions (exact if discordant < 25); matched-pairs odds ratio
  b_only/a_only with Wald 95% CI; bootstrap CIs are 95% percentile intervals of b - a.
- ASSUMPTION: the FULL sample, its E features and the 21 interest columns are taken from
  ci_common.load_base(); the EARLY samples are built with wdearly_common.build_sample("EARLY",
  cutoff=t), the builder used in the earlier EARLY rounds, imported read-only. Nothing from the
  final_ round is read or imported.
- Sanity check before reporting: the base and base + presentation one-hot arms are compared with
  the earlier predictions of the same construction (FULL: robustness E, ci1 E_course; EARLY:
  C_t{t}_course in early_stratcv_oof_predictions.csv).

## Steps and BH families

- Step 1a: ICC(1), one-way ANOVA estimator, across the 22 presentations and across the 7
  modules, for the binary outcome and each of the 21 interest columns, in FULL, EARLY_t28 and
  EARLY_t56. Undefined when the denominator is 0 (e.g. constant column). N per group reported.
- Step 1b: arms base, base_course (+ presentation one-hot), W (+ course-centered interest
  columns only), M (+ course-mean interest columns only), WB (+ both); LR and GBM; stratified
  5-fold; FULL, EARLY_t28, EARLY_t56. Comparisons W vs base, M vs base, WB vs M.
  BH family: each (setting x model family), 3 tests.
- Step 2: leave-one-module-out (7 folds). For each held-out module, every training row of a
  student (id_student) who also appears in the held-out module is removed from training
  (rows removed reported per fold). No course one-hot. base vs base + course-centered interest
  columns. LR and GBM; FULL, EARLY_t28, EARLY_t56. BH family: each (setting x model family)
  (1 test per family). Per-module table: n, pass rate, accuracy of both arms, difference.
- Step 3: within each of the 7 modules (all its presentations, presentation one-hot included),
  stratified 5-fold inside the module, base_course -> base_course + course-centered interest
  columns; EARLY_t28 and EARLY_t56; LR and GBM. Per-module N, delta-Accuracy, bootstrap CI and
  bootstrap SE (SD of the 1000 bootstrap differences), McNemar. BH family: all 7 x 2 x 2 = 28
  tests together. Random-effects pooling of the 7 module-level delta-Accuracy values per model
  family and cutoff, using the bootstrap SEs: DerSimonian-Laird (pooled estimate, 95% normal
  CI, tau^2, I^2) and Hartung-Knapp CI (t distribution, df = 6).
- Step 4: second-dataset feasibility check only; no analysis.

## Rules (copied verbatim from the owner)

- W vs base positive with M vs base not positive: signal is within-course. M vs base positive: between-course context.
- Leave-one-module-out gain: generalization to an unseen module. No gain: course-specific.
- A module whose CI contains both 0 and the pooled estimate is labeled "inconclusive", not "does not replicate".
- Replication: at least 5 of 7 modules meeting the criterion AND I^2 below 50% (both model families) = consistent. Fewer than 5 modules AND I^2 at or above 50% = course-specific. Any other combination = mixed (report as mixed, no further label).
