cutoff-first truncation, as in earlier EARLY rounds), and FULL (D/E row set; base = E).
- base_course   = base features + presentation one-hot
- base_course_z = base features z-scored within presentation + presentation one-hot. z = (x - presentation
  mean) / presentation SD (ddof 0), computed over that presentation's students in the analysed sample,
  features only, no labels. If the SD is 0 the z value is 0; missing values stay missing (LR median
  imputation, GBM native handling).
- base_course_z_full21 = base_course_z + full21_ctr (21 interest columns centered within presentation,
  features only, no labels; constant columns centered to 0).
Comparisons: base_course -> base_course_z; base_course_z -> base_course_z_full21. LR and GBM, stratified
5-fold seed 42, key-aligned McNemar, OR with Wald 95% CI, student-level bootstrap (1000, seed 42).
